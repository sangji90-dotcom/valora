# 사이트 관리 방법

이 문서는 사이트에 제품과 글을 직접 올리는 방법을 설명합니다.
컴퓨터를 잘 다루지 않아도 따라 할 수 있게 썼습니다.

납품 시 이 파일의 `○○○` 부분을 실제 값으로 바꿔서 전달합니다.

---

## 시작하기 전에

관리화면 주소와 로그인 계정을 받으셨을 겁니다.

| | |
| --- | --- |
| 관리화면 주소 | `https://○○○.sanity.studio` |
| 사이트 주소 | `https://○○○` |
| 로그인 | 받으신 이메일로 로그인 |

**즐겨찾기에 두 주소를 모두 추가해 두세요.**

---

## 가장 먼저 알아둘 것

**저장하면 바로 사이트에 보이지 않습니다.**

저장 후 사이트가 다시 만들어지는 데 **1~2분** 걸립니다.
저장하고 바로 사이트를 새로고침하면 예전 내용이 보이는 게 정상입니다.
커피 한 잔 따르고 오시면 바뀌어 있습니다.

5분이 지나도 안 바뀌면 맨 아래 "문제가 생겼을 때"를 보세요.

---

## 제품 추가하기

1. 관리화면에 들어가서 왼쪽 **제품** 을 누릅니다
2. 오른쪽 위 **+** 버튼을 누릅니다
3. 아래 칸을 채웁니다

### 반드시 채워야 하는 것

| 칸 | 설명 |
| --- | --- |
| **제품명** | 화면에 보일 이름 |
| **URL 주소** | 제품명 옆 **Generate** 를 누르면 자동으로 만들어집니다. 한글이면 안 만들어지니 영문으로 직접 적으세요 (예: `pro-shield-900`) |
| **한 줄 설명** | 목록에서 제품명 아래에 보입니다. 120자까지 |
| **카테고리** | 정해진 것 중에서 고릅니다 |
| **대표 이미지** | 아래 "사진 올리기" 참고 |

### 채우면 좋은 것

- **사양** — 모델명, 크기, 무게처럼 표로 보여줄 내용. `+ Add item` 으로 한 줄씩 추가합니다
- **가격** — 숫자만 적으세요. 쉼표나 "원"은 빼고 `189000` 처럼. 비워두면 "가격 문의"로 나옵니다
- **본문** — 제품 상세 설명. 글자를 드래그하면 굵게·제목·목록을 지정할 수 있습니다
- **홈 대표 제품으로 노출** — 켜면 첫 화면에 나옵니다

4. 오른쪽 아래 **Publish** 를 누릅니다

### 본문에 표 넣기

본문 칸 오른쪽 아래 **+** 를 누르면 **표** 를 고를 수 있습니다.

- **줄** 을 하나씩 추가하고, 각 줄 안에서 **칸** 을 왼쪽부터 채웁니다
- 모든 줄의 칸 수를 똑같이 맞추세요. 어긋나면 화면에서 표가 비뚤어집니다
- **첫 줄을 제목 줄로** 를 켜면 첫 줄이 굵은 머리글이 됩니다
- 칸 안에는 **글자만** 넣을 수 있습니다. 굵게·링크는 들어가지 않습니다

**Publish 를 누르지 않으면 사이트에 안 나옵니다.** 저장만 되고 아직 공개가 아닌 상태입니다.

---

## 사진 올리기

**대표 이미지** 칸에 사진을 끌어다 놓거나, 칸을 눌러 파일을 고릅니다.

- 가로 1200픽셀 이상을 권장합니다. 작으면 흐리게 보입니다
- 휴대폰으로 찍은 사진은 그대로 올려도 됩니다. 자동으로 줄여서 씁니다
- 사진에서 중요한 부분이 잘린다면, 사진을 누르고 **Edit** 에서 중심점을 옮기세요

---

## 제품 수정하기

1. **제품** 목록에서 고칠 제품을 누릅니다
2. 내용을 고칩니다
3. 오른쪽 아래 **Publish** 를 누릅니다

고치는 중에 창을 닫아도 내용은 남아 있습니다. 다만 **Publish 전까지는 사이트에 반영되지 않습니다.**

---

## 제품 내리기 — 두 가지 방법

### 방법 1. 잠시 내리기 (권장)

제품을 열고 **작성 중** 을 켠 뒤 Publish 합니다.
사이트에서 사라지지만 내용은 그대로 남아 있어서, 나중에 다시 켜면 돌아옵니다.

품절, 시즌 종료, 재입고 예정인 경우에 쓰세요.

### 방법 2. 완전히 지우기

제품을 열고 오른쪽 아래 점 3개 → **Delete** 를 누릅니다.

**되돌릴 수 없습니다.** 단종되어 다시 팔 일이 없는 제품만 지우세요.

> 판매를 중단했지만 문의는 받고 싶다면, 지우는 대신 **판매 상태** 를 "단종"으로
> 바꾸는 방법도 있습니다. 제품 페이지는 남고 "단종" 표시가 붙습니다.

---

## 홈 배너 바꾸기

왼쪽 **홈 배너** 를 누릅니다. 첫 화면 맨 위에서 넘어가는 큰 그림입니다.

- **배경 이미지** 는 가로로 아주 넓게 잘립니다. 가로 1920픽셀 이상, 중요한 내용은 가운데에 두세요
- **문구 위치** 는 사진에서 비어 있는 쪽으로 고르세요
- 글자가 사진에 묻혀 안 읽히면 **사진 어둡게** 를 "약하게"부터 올려보세요
- **순서** 숫자가 작을수록 먼저 나옵니다
- 잠시 내리려면 **숨기기** 를 켜세요

---

## 회사소개·개인정보처리방침 고치기

왼쪽 **페이지** 를 누릅니다.

주소·전화번호가 바뀌었을 때 여기서 고치면 됩니다.

> **개인정보처리방침은 "작성 중"을 켜지 마세요.**
> 문의를 받는 동안에는 항상 공개되어 있어야 합니다. 법적으로 필요한 페이지입니다.
> 내용을 바꿔야 한다면 고쳐서 Publish 하시고, 큰 변경이라면 먼저 확인받으세요.

---

## 하면 안 되는 것

**개인정보를 넣지 마세요.**
고객 이름, 전화번호, 주소, 문의 내용 같은 것은 이 관리화면에 넣으면 안 됩니다.
여기 있는 내용은 인터넷에서 누구나 읽을 수 있는 상태로 저장됩니다.
제품 소개와 회사 소개만 넣으세요.

**URL 주소는 한 번 정하면 바꾸지 마세요.**
바꾸면 기존 주소로 들어오던 링크가 전부 끊깁니다. 검색 결과에서도 사라집니다.

**카테고리를 새로 만들 수는 없습니다.**
목록에 없는 카테고리가 필요하면 연락 주세요. 사이트 쪽도 같이 고쳐야 합니다.

## 문제가 생겼을 때

### 저장했는데 사이트에 안 보여요

1. **Publish 를 눌렀는지** 확인하세요. 가장 흔한 원인입니다
2. **5분 기다렸는지** 확인하세요
3. **작성 중 / 숨기기** 가 켜져 있지 않은지 확인하세요
4. 그래도 안 되면 아래로

### 사이트가 아예 안 바뀌어요

필수 칸이 비어 있으면 사이트 만들기가 실패합니다.
이때 **사이트는 예전 상태 그대로 살아 있습니다.** 깨지지 않으니 안심하세요.

제품을 열어서 빨간 표시가 있는 칸이 없는지 확인하고, 채운 뒤 다시 Publish 하세요.

### 실수로 지웠어요

바로 연락 주세요. 시간이 지나면 복구가 어려워집니다.
