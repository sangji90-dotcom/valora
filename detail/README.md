# 제품 상세 이미지

모레모 같은 세로로 긴 커머스 상세 이미지를 만드는 곳입니다.
디자인 파일이 아니라 HTML 인 이유 — 수량·납기·사양은 반드시 바뀌는데,
이미지로만 갖고 있으면 글자 하나 고칠 때마다 디자인 파일을 열어야 합니다.

## 만들기

```
node detail/shoot.mjs            # detail/out/ 에 PNG 가 생깁니다
node detail/shoot.mjs ./out capsule.html   # 다른 제품
```

- `dispenser-full.png` — 전체 한 장 (사이트 상세 탭, PDF 용)
- `dispenser-01.png` ~ — 섹션별 조각 (스마트스토어 등은 여러 장으로 올립니다)

폭 860px, 2배 해상도로 찍습니다. 국내 커머스 상세의 관행입니다.

## 쓰면 안 되는 것

- **특허·인증·기술이전 같은 자격 주장.** 발로라의 특허는 출원 상태입니다.
  등록처럼 읽히게 쓰면 허위표시가 되고, 확인 책임이 따라붙습니다.
  이 문서는 기능과 쓰는 법만 다룹니다.
- **고객 후기.** 판매 전이라 존재하지 않습니다. 만들지 않습니다.
- **효능 표현.** 세정력·피지·두피 개선 같은 말은 화장품법상 실증자료가
  필요합니다. 제품이 어떻게 동작하는지(필름이 녹는다, 한 번에 한 알)만
  적으면 그 선을 넘지 않습니다.
- **근거 없는 숫자.** 환경 수치는 산출 기준과 단서를 함께 적어야 합니다.

## 사진이 오면

제품 비주얼은 전부 도식입니다. `.visual` 안의 `<svg>` 를 `<img>` 로
바꾸면 됩니다. 비율을 맞춰 뒀습니다.

촬영본으로 바꾼 뒤에는 `시안 · 실물 사진 아님` 배지(`.draft-tag`)를
지우세요. 그 배지가 남아 있으면 실물 사진도 도면으로 읽힙니다.
